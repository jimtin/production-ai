# Content Status Rules

Use this reference when producing episode tables or identifying missing content.

## Status Definitions

- `published`: a public YouTube video is verified or the user supplied confirmed published status.
- `scheduled`: a scheduled/private YouTube video and publish date are verified or supplied.
- `proposed next`: the user explicitly chose it as upcoming, but no scheduled video is verified.
- `artifact ready`: a saved content artifact exists, usually `docs/content/<topic>-video-breakdown.md`.
- `content-map idea`: the topic appears in `docs/content/content-map.md`, but may not have a dedicated episode artifact.
- `missing`: under the definition requested, no qualifying status exists.

## Reporting Rules

- State the definition before saying an item is missing.
- Do not treat a generic published companion video as a dedicated episode unless the user asks for broad companion coverage.
- Do not treat `content-map.md` as a scheduled episode.
- Distinguish "idea exists" from "video artifact exists."
- For ordered upcoming lists, preserve user-proposed order first, then sort remaining items by foundational dependency.
